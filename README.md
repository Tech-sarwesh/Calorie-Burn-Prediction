# 🥗 Calorie Burn Prediction
This project is a Calorie Burn Prediction system. It consists of a FastAPI backend that predicts calories burned based on user inputs and a frontend demo built with HTML, CSS, and JavaScript.

# Features
**CODE_BY:** [tech_sarwesh](https://github.com/tech-sarwesh)

- Predict calories burned based on:
  * Age (15–60)
  * Gender (0: Female, 1: Male)
  * Sleep hours
  * Stress level (1–10)
  * Weight (kg)
- Simple and clean frontend demo for testing the API.
- CORS enabled for frontend integration.

## Demo Frontend 

Input all required values in the form.
Click Predict Calories Burned.
The prediction result is displayed below the form.
